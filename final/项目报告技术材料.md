# 旧物循用校园二手交易平台：项目报告技术材料

> 本文不包含功能图和流程图，主要整理技术框架、项目效果图建议、重要代码、主要程序接口及接口函数。

## 一、技术框架

### 1. 总体架构

项目采用轻量级 B/S 架构和 Flask 单体应用结构：

```text
浏览器
  ├─ HTML5 / CSS3 / JavaScript
  ├─ Jinja2 服务端模板
  └─ Fetch API（AI 标签生成）
          │ HTTP
          ▼
Flask Web 应用
  ├─ 路由与业务控制层（app.py）
  ├─ AI 服务层（services/ai_client.py）
  ├─ 商品检索层（services/product_search.py）
  ├─ ORM 数据访问层（Flask-SQLAlchemy）
  └─ 登录状态与权限控制（Session + 装饰器）
          │
          ├─ SQLite 本地数据库
          ├─ uploads 本地图片存储
          └─ DeepSeek Chat Completions API
```

### 2. 技术选型

| 层次 | 使用技术 | 主要作用 |
| --- | --- | --- |
| 前端展示层 | HTML5、CSS3、JavaScript | 页面结构、响应式界面、交互逻辑 |
| 模板引擎 | Jinja2 | 服务端渲染商品、用户、订单等动态数据 |
| Web 框架 | Flask 3.0.3 | 路由管理、请求处理、Session、模板渲染 |
| ORM | Flask-SQLAlchemy 3.1.1 | 数据模型定义、查询及事务处理 |
| 数据库 | SQLite | 保存用户、商品、订单、积分、好友和聊天数据 |
| 安全组件 | Werkzeug 3.0.3 | 密码哈希校验、安全文件名处理 |
| AI 模型 | DeepSeek `deepseek-chat` | 用户需求理解、搜索意图提取、商品标签生成 |
| AI 通信 | Python `urllib.request` + JSON | 调用兼容 Chat Completions 的 HTTP API |
| 图片存储 | 本地 `uploads` 目录 | 保存商品图片和用户头像 |

### 3. 后端模块划分

| 文件 | 职责 |
| --- | --- |
| `app.py` | 创建 Flask 应用、注册路由、处理核心业务和后台管理 |

| `static/css/style.css` | 全站统一 UI、商品卡片、AI 卡片和响应式样式 |

```python
def create_app():
    app = Flask(__name__)
    app.config.from_object(Config)

    os.makedirs(app.config["UPLOAD_FOLDER"], exist_ok=True)
    os.makedirs(os.path.join(app.config["UPLOAD_FOLDER"], "avatars"), exist_ok=True)
    db.init_app(app)

    with app.app_context():
        ensure_database_schema()

    register_routes(app)
    register_commands(app)
    return app
```

说明：加载配置，初始化上传目录和数据库，然后统一注册页面路由与命令行命令。

```python
user = User.query.filter_by(account=account).first()
```

### 4. DeepSeek 搜索意图解析

位置：`services/ai_client.py` 中的 `parse_product_search_intent()`。

```python
payload = {
```


说明：强制模型返回 JSON，便于程序稳定提取搜索摘要、关键词、标签及积分范围。

### 5. 商品召回与相关度排序

位置：`services/product_search.py` 中的 `search_products()` 和 `_score_product()`。

```python
for product in candidates:
    if condition_groups and not _matches_all_condition_groups(product, condition_groups):
        continue
    score = _score_product(product, query_text, intent, terms)
    if score > 0:
        scored_products.append((score, product.create_time, product))

scored_products.sort(key=lambda item: (item[0], item[1]), reverse=True)
```

评分规则：

- 标签命中权重最高；
- 标题命中权重高于描述命中；
- 支持“吃的、可吃、食品、零食”等同义词扩展；
- 支持最低和最高积分过滤；
- 浏览量作为轻量热度加分；
- 分数相同时优先显示较新商品。

```python
tags = clean_generated_product_tags(
```

### 7. 积分交易原子处理

位置：`app.py` 中的 `create_order()`。

```python
buyer.points_balance -= product.points
seller.points_balance += product.points
product.status = "已售出"
db.session.add(TradeOrder(
    buyer_id=buyer.id,
    seller_id=seller.id,
    product_id=product.id,
    points=product.points,
    status="已完成",

add_point_record(buyer, -product.points, "购买", f"购买商品：{product.title}")

```

说明：一次事务内完成买家扣分、卖家加分、商品状态变更、订单创建和双方积分流水记录。

### 9. 页面滚动位置恢复

位置：`static/js/main.js`。

```javascript
const scrollKey = `campus_scroll:${window.location.pathname}${window.location.search}`;
```

## 六、报告可用总结

本项目基于 Flask 和 SQLite 构建校园二手交易平台，在传统商品发布、浏览、收藏和积分交易功能上，加入了 DeepSeek 自然语言理解能力。系统可将用户模糊需求转换为关键词、标签和积分条件，并结合商品标题、描述、标签、发布时间及浏览热度完成匹配排序。同时，AI 还能根据商品描述自动生成标签。项目采用服务层拆分 AI 调用与检索逻辑，在外部 AI 不可用时提供关键词搜索和本地标签规则降级，兼顾智能性、稳定性和可维护性。
